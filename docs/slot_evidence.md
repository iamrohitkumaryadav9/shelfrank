## Room rule

A room word is part of the product type when it lies inside a phrase that names a product category and
continues past it. The phrase list is class names and category path segments, and "patio" equals "outdoor".

| Example | Result | Expected |
| --- | --- | --- |
| dining table | product type | product type |
| kitchen island | product type | product type |
| bathroom vanity | product type | product type |
| outdoor dining set | product type | product type |
| bathroom rug | slot | slot |
| patio umbrella | slot | slot |
| bedroom lamp | slot | slot |

Which phrase list reproduces the examples:

| Phrase list | Examples it gets wrong |
| --- | --- |
| every class name | bathroom vanity, patio umbrella |
| classes with 30+ products | bathroom vanity |
| those, plus path segments with 500+ | none |
| **those, plus path segments with 100+ (implemented)** | none |
| those, plus path segments with 79+ | patio umbrella |
